KD-дерево: как строится и как ищет

Слева — облако точек и рекурсивное разбиение пространства. Справа — само дерево как иерархический граф. Кликни по любой точке слева, чтобы увидеть, как дерево ищет её k ближайших соседей.

Облако точек и разбиение

Кликни по точке — запустится поиск k соседей
разрез по X разрез по Y активный узел отсечённая область найденные соседи

Структура дерева

В каждом узле — точка-разделитель. Слева — меньшие, справа — большие.
Нажми «Построить дерево», чтобы увидеть пошаговое построение. Каждый шаг делит одну область пространства пополам — сначала по X, потом по Y, потом снова по X и так далее.
