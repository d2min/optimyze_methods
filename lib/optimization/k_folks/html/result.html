Оптимизация поиска k_folks

Слева — старый алгоритм: полный попарный перебор. Справа — новый: k-D дерево + k ближайших соседей.

До: попарный перебор O(N²)

Сравнений: 0 / 0
Линий: 0

После: k-D дерево O(N log N + Nk)

Операций: 0 / 0
Линий: 0

Рост числа операций от N (при фиксированном k)

Старый: N(N−1)/2 Новый: N·log₂N + N·k
