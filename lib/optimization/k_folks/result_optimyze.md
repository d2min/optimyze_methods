# Оптимизация поиска `k_folks`

## Исходный алгоритм

Для каждой из `N` точек вычислялось расстояние до всех остальных:

`d(p, q) = |px - qx| + |py - qy| + |pz - qz|`.

Это метрика Манхэттена (L1), соответствующая описанному радиусу
октаэдрической формы. Затем для каждой строки выбирались `k` минимальных
расстояний. Несмотря на блочную обработку, алгоритм сравнивал каждую точку
с каждой, поэтому его временная сложность составляла **O(N²)**.

## Изменение

Полный попарный перебор заменён на `scipy.spatial.cKDTree`:

1. Дерево строится один раз по исходным координатам.
2. Для каждой точки запрашиваются `k + 1` кандидатов с параметром `p=1`,
   который задаёт ту же метрику L1.
3. Индекс самой точки удаляется из кандидатов, после чего записываются
   `k` соседей. Это корректно работает и при совпадающих координатах, когда
   дерево может не включить индекс текущей точки в набор кандидатов.
4. Запросы выполняются блоками, чтобы ограничить размер временных массивов.

Публичная функция и её параметры не менялись. Сохраняются форма и тип
результирующей матрицы, формат меток классов, порядок «target, затем соседи»
и проверки входных данных. При равных расстояниях конкретный порядок
эквивалентных соседей может отличаться от прежней реализации: их расстояния
одинаковы.

## Сложность

Обозначения: `N` — число точек, `k` — число соседей.

| Этап | Ожидаемая сложность | Худший случай |
|---|---:|---:|
| Построение дерева | O(N log N) | O(N log N) |
| Запросы ближайших соседей | O(N log N + Nk) | O(N² + Nk) |
| Итого | **O(N log N + Nk)** | **O(N² + Nk)** |

Добавка `Nk` необходима, чтобы вернуть сами `k` соседей для каждой точки.
Дерево особенно ускоряет обычные облака точек в низкоразмерном пространстве;
как и другие пространственные деревья, в вырожденном худшем случае может
приблизиться к полному перебору.

Результат записывается в NPY последовательно блоками: файл на диске занимает
**O(Nk)**, но целиком не резервируется в оперативной памяти. Для запроса
соседей обрабатывается не более 100 000 пар «точка-сосед» за блок, поэтому
временная память ограничена размером блока; основная память — входные точки,
признаки и дерево **O(N)**. Уменьшение размера блока снижает пик памяти за
счёт дополнительных запросов и увеличения времени работы.
