## Репозиторий команды красных

Данные репозиторий является набором готовых скриптов для оптимизации дынных типа:
```txt
a x y z
```

Где a - класс точки xyz - соответствубщие координаты точки
Пример:
```txt
2 0.100000 11.100000 13.930744
```

Пример файла можно найти по `examples/datasets/`

      <td ><code>Статистическая фильтрация (SOR)</code></td>

      <td><code>Радиусная фильтрация (ROR)</code></td>

    </tr>

      <td>Разбиение пространства на 3D-кубики с оставлением одной точки на воксель. Равномерное распределение, сохранение геометрии.</td>
    </tr>
    <tr>
      <td><code>Farthest Point Sampling (FPS)</code></td>
      <td>Итеративный выбор максимально удалённых точек. Равномерно покрывает облако, сохраняет геометрию лучше случайного.</td>
    </tr>
    <tr>
      <td><code>Удаление дубликатов</code></td>
      <td>Удаление точек с идентичными или почти идентичными координатами.</td>
    </tr>
