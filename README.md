## Репозиторий команды красных

Данные репозиторий является набором готовых скриптов для оптимизации дынных типа:
```txt
a x y z
```

Где a - класс точки xyz - соответствубщие координаты точки
Пример:
```txt
2 0.100000 11.100000 13.930744
```

Пример файла можно найти по `examples/datasets/`

      <td><code>Радиусная фильтрация (ROR)</code></td>

    </tr>
    <tr>
      <td><code>Фильтрация по классу</code></td>
      <td>Полное удаление точек определённого класса (например, шум класса 1). 100% точность, но теряет данные.</td>
    </tr>

      <td rowspan="3">Прореживание (Downsampling)</td>

    </tr>

      <td><code>Случайное прореживание</code></td>

    </tr>
