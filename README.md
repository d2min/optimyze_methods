## Репозиторий команды красных

Данные репозиторий является набором готовых скриптов для оптимизации дынных типа:
```txt
a x y z
```

Где a - класс точки xyz - соответствубщие координаты точки
Пример:
```txt
2 0.100000 11.100000 13.930744
```

Пример файла можно найти по `examples/datasets/`

### Использование как библиотеки

Для обработки папки используйте файлы `.xyz` с колонками `class, x, y, z`
или `.npy` с массивом формы `(N, 4)` (`class, x, y, z`). Также `.npy`
поддерживает массив формы `(N, 3)` (`x, y, z`); таким точкам назначается класс 0.
Формат каждого файла выбирается автоматически. Для динамической обработки
используйте генератор: результат по каждому файлу поступает сразу после его
обработки, не дожидаясь остальных файлов:

```python
from lib import iter_process_directory

for file_result in iter_process_directory("path/to/xyz-files"):
    print(file_result.input_path, file_result.success, file_result.error)
```

Если нужен единый итоговый отчет после обработки всех файлов, используйте обычный
вызов с `return`:

```python
from lib import process_directory

report = process_directory("path/to/xyz-files")
print(report.success, report.files)
```

В обычном режиме pipeline прореживает и очищает облако, а затем сохраняет
результат в `exports/<имя>_cleaned.npy` с колонками `class, x, y, z, hag, nx,
ny, nz, ground`: высота над землёй, компоненты вектора нормали и флаг земли.
Поиск соседей `k_folks` временно отключён.

Для быстрой проверки прореживания запустите CLI с флагом `--debug`:

```powershell
python .\lib\__main__.py .\assets\ --debug
```

В этом режиме каждое облако экспортируется в `exports/<имя>_downsampled.xyz`
сразу после прореживания (колонки `class, x, y, z`); очистка пропускается.

По умолчанию библиотечный API не очищает папку экспорта и не выводит прогресс
в консоль. Параметры `clear_export_dir=True` и `verbose=True` включают очистку
папки перед запуском и консольные сообщения соответственно. Ошибки отдельного
файла находятся в его `FileProcessingResult.error`; ошибки входной папки
возникают как исключения. API также поддерживает `debug=True` с тем же быстрым
режимом экспорта.
